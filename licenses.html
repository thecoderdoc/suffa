Ses tanıma modelleri

Suffa, Kur'an okumasını cihaz üzerinde tanımak için iki ses tanıma modeli kullanır.

Ücretsiz sürüm: Tarteel Whisper Base Arabic Quran.
Yaratıcı: Tarteel AI.
Lisans: Apache License 2.0 (apache.org)
Temel model: OpenAI Whisper Base (MIT)
Değişiklik: Model cihazda çalışacak biçime (GGML, q5_1 nicemleme) dönüştürülmüş hâlde kullanılır.

Suffa Plus: FastConformer Quran Arabic.
Yaratıcı: Mohammed.
Lisans: Creative Commons Attribution 4.0 International (CC BY 4.0)
Temel model: NVIDIA stt_ar_fastconformer, CC BY 4.0
Eğitim verisi (model kartında bildirilen): tarteel-ai/everyayah
Değişiklik bildirimi: Model, ONNX biçimine ve int8 nicemlemeye dönüştürülmüş hâlde kullanılır.

Speech recognition models

Suffa uses two speech recognition models to recognise Quran recitation on the device.

Free tier: Tarteel Whisper Base Arabic Quran.
Creator: Tarteel AI.
License: Apache License 2.0 (apache.org)
Base model: OpenAI Whisper Base (MIT)
Changes: The model is used in a converted form for on-device use (GGML, q5_1 quantization).

Suffa Plus: FastConformer Quran Arabic.
Creator: Mohammed.
License: Creative Commons Attribution 4.0 International (CC BY 4.0)
Base model: NVIDIA stt_ar_fastconformer, CC BY 4.0
Training data (as stated on the model card): tarteel-ai/everyayah
Modification notice: The model is used in a form converted to ONNX with int8 quantization.
